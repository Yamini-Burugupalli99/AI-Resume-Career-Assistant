# AI Resume & Career Assistant

An AI-powered career assistant that helps job seekers analyze their resumes, compare them with job descriptions, identify skill gaps, improve resume content, and prepare for interviews.

## Planned Features

- Resume PDF/DOCX upload
- Resume analysis
- Job description matching
- Skill gap analysis
- Resume improvement suggestions
- Personalized learning recommendations
- Interview question generation
- AI mock interviews
- Interview answer evaluation
- Analysis history

## Tech Stack

### Frontend

### Backend

- Express.js

### Database
